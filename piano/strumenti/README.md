## Come usare la dashboard (07)
1. Apri il file con Excel o Google Fogli (separatore: punto e virgola).
2. Le colonne **OBIETTIVO_…** vengono dal modello economico (scenario realistico): **non modificarle**.
3. Ogni mese compila le altre colonne. Le fonti dei primi colloqui si ricavano dalla domanda fissa "Come mi ha conosciuto?".
4. In `note_azione_correttiva` scrivi **una sola azione** per il mese successivo.
5. Ogni trimestre chiedi a Claude Code: *"Leggi `piano/strumenti/07_dashboard_kpi_mensile.csv`, confronta risultati e obiettivi e aggiorna modello e roadmap."*
